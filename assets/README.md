# Assets

## `brand/` — MEDHUB logo (final, not a placeholder)

Real MEDHUB brand assets, extracted directly from the client-supplied
`medhub_logos_1.pdf` (variant "a2", page 2) as vector paths — not traced
or eyeballed. Colors are the exact fill values from that file.

| File | Used for |
|---|---|
| `medhub-mark.svg` | Icon only (no wordmark) |
| `medhub-logo.svg` | Full lockup: icon + "MEDHUB" wordmark |
| `medhub-logo.png` | Raster export of the lockup, transparent background — used as the default `og:image` |
| `favicon.svg` | Browser-tab icon (same as `medhub-mark.svg`) |

Brand colors (also in `css/style.css` `:root`): `#2315FF` (primary),
`#0068FF` (secondary), `#0000C1` (dark), `#FCEE21` (yellow accent).

Sheba Medical Center's own logo files were **not** copied — that's a
separate organization's trademark. Where Sheba is mentioned in body
content, it's as text/photography, never their logo.

## `temp-dev-refs/` — temporary, for visual QA only

Photos of the Sheba Medical Center facility, pulled from
shebaonline.ru as **temporary development placeholders** so the page
isn't full of gray boxes during design review:

| File | Used for |
|---|---|
| `hero-staff.jpg` | Hero section photo |
| `advantages-building.jpg` | Advantages section photo |
| `cta-consultation.jpg` | CTA band photo (doctor + patient) |
| `cta-ring.svg` | Decorative ring behind CTA band text (abstract shape, not photography — low-risk to keep) |

**Before launch, replace the three JPGs with licensed Sheba Medical
Center photography** at the same crop/aspect ratio (hero ≈760×310,
advantages ≈535×420, CTA band = full-bleed portrait). Each `<img>` tag
generated by `build.js` is marked with:

```html
<!-- TEMP dev reference from shebaonline.ru — replace with a licensed Sheba Medical Center photo -->
```

`title-band-bg.svg` (Sheba's own decorative theme swoosh, downloaded in
an earlier pass) has been removed from use — it carried Sheba's old
pink/teal brand colors, which would have visually contradicted the
MEDHUB rebrand. The title band is now a flat `--medhub-dark` fill.
