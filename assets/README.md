# Assets

## `brand/` — MEDHUB + Sheba Medical Center co-branding (real assets, not placeholders)

| File | Source | Used for |
|---|---|---|
| `medhub-mark.svg` | Client-supplied `medhub_logos_1.pdf` (variant "a2", page 2) — vector paths extracted directly, not traced or eyeballed | Icon only (no wordmark) |
| `medhub-logo.svg` | Same PDF | Full lockup: icon + "MEDHUB" wordmark |
| `medhub-logo.png` | Rendered from `medhub-logo.svg` | Raster export, transparent background |
| `favicon.svg` | Same as `medhub-mark.svg` | Browser-tab icon — MEDHUB only, per spec (`medhub.group` is MEDHUB's domain) |
| `sheba-medical-center-logo.svg` | Official Sheba Medical Center logo file (the real "SHEBA GLOBAL · Tel HaShomer · Patient Services" lockup), used here under MEDHUB's stated contractual right to display it as an authorized representative | Co-branded lockup in the header and footer, and the Sheba block on the homepage |
| `medhub-sheba-og.png` | Composited from the two files above (real logos, no AI-generated artwork) at 1200×630 | Default `og:image` for social previews |

Both logo files are used **as-is** — no recoloring, redrawing, or re-proportioning. Brand colors used elsewhere on the site (also in `css/style.css` `:root`): `#2315FF` (primary), `#0068FF` (secondary), `#0000C1` (dark), `#FCEE21` (yellow accent) — extracted from the MEDHUB mark specifically; the site's own digital identity is built around these, not Sheba's palette.

**Where both logos appear:** header (`.brand-lockup`, every page), footer (`.footer-top .brand-lockup`, every page), and the "Sheba Medical Center" teaser block on the homepage (`.sheba-logo-block`). Sheba's logo is a plain navy wordmark, so on the dark navy footer it sits on a small white chip (`.footer-top .logo--sheba`) for contrast — the file itself is untouched, only its background is a white rectangle.

**No temporary logo placeholders remain** — both logo files are the real, final assets.
